# Instrucciones del proyecto

## Estilo de código
- Todo el código nuevo debe ser **corto** y **modular**.
- Usar **orquestadores**: un componente/función principal que coordina y delega la lógica en piezas pequeñas y reutilizables (hooks, servicios, subcomponentes), en lugar de archivos largos con toda la lógica junta.
- Usar **Tailwind (NativeWind)** para los estilos: preferir `className="..."` sobre `StyleSheet.create` en el código nuevo.
